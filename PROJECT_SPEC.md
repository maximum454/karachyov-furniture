## 1. Цель проекта
Создать автоматический backend-driven калькулятор себестоимости и розничной цены для мебельного интернет-магазина, а также связать его с обработкой лидов и Kanban-доской для управления заказами.

## 2. Архитектура файлов
* **`calculator_api.php`** — бэкенд-контроллер для расчета цен. Принимает параметры (`spec_id`, `fabric_id`, `has_mechanism`), вычисляет стоимость материалов, ткани и наценку, возвращая JSON с ценами.
* **`kanban_api.php`** — бэкенд-контроллер для Kanban-доски. Управляет статусами и перемещением заказов/лидов по производственным этапам (например, в работе, раскрой, сборка, готовность).
* **`save_lead.php`** — бэкенд-обработчик формы заказа/корзины. Принимает данные клиента и выбранную конфигурацию мебели, создает лид в CRM Bitrix и связывает его с рассчитанной стоимостью.
* **Фронтенд (`template.php` + JS)** — собирает параметры на карточке товара, отправляет запросы в API и выводит актуальные цены и элементы управления.

## 3. Структура инфоблоков и свойства

### ИБ 49: Спецификации моделей (`FURNITURE_SPECIFICATIONS`)
* `SPEC_TYPE` — Тип спецификации (Список). Делит спецификации на два типа (см. раздел 3.1):
  * **Базовый размер** — спецификация, которая задает РАЗМЕР спального места и материалы для его изготовления.
  * **Опция** (`XML_ID = OPTION`) — дополнение к базовой комплектации: ножки, подъемный механизм и т.п.
* `SIZE` — Размер спального места (Список)
* `MODEL_ID` — Привязка к модели (Привязка к элементу)
* `CUTTING_MAPS` — Чертежи и карты раскроя (Файл, множ.)
* `MATERIALS_REF` — Состав материалов (Привязка к ИБ 50, множ.)
* `MATERIALS_QTY` — Количество материалов (Строка, множ.)
* `FABRIC_CONSUMPTION` — Расход ткани в п.м. (Число)
* `PRICE_MULTIPLIER` — Коэффициент наценки (Число)

### 3.1. Типы спецификаций (как это работает в каталоге)
У каждой модели (карточки товара) в каталоге привязывается набор спецификаций из ИБ 49 (свойство `SPECIFICATIONS` на товаре). Спецификации делятся по `SPEC_TYPE`:

1. **Базовый размер** — в спецификации задан размер кровати (`SIZE`) и материалы для ее изготовления (`MATERIALS_REF` → ИБ 50, `MATERIALS_QTY`). На витрине такие спецификации выводятся в блоке "Размер" карточки как кнопки выбора размера (активная подсвечена, `data-spec-id`).
2. **Опция** — дополнения: ножки, подъемный механизм и т.п. В коде определяются строго по `XML_ID = 'OPTION'` свойства `SPEC_TYPE`. На витрине выводятся в блоке "Комплектация и опции" как чекбоксы.

Материалы для изготовления (что идет в производство/бланк закупки) спецификация берет из справочника материалов ИБ 50.

### ИБ 50: Справочник материалов (`FURNITURE_MATERIALS`)
* `PRICE` — Закупочная цена за единицу (Число)
* `UNIT` — Единица измерения (Список)
* `STOCK_QUANTITY` — Остаток (Число)

### ИБ 48: Коллекции тканей (`FURNITURE_FABRICS`)
* `PRICE_PER_METER` — Цена за 1 погонный метр (Число)
* `COLLECTION` — Название коллекции (Строка)
* `FABRIC_TYPE` — Тип ткани (Список)

### ИБ 51: SKU цветов (Торговые предложения тканей)
* `CSTAR_LINK` — Привязка цвета к коллекции из ИБ 48.
* Также используются: `IS_MAIN_PREVIEW` (галочка "главный цвет для превью"), `COLOR_CODE`, `COLOR_NAME`, `COLOR_HEX`, картинка превью.

**ИБ 46:** (`CATALOG`) — Каталог моделей (карточки товаров)
* `PRICE` — Цена (Число)
* `SPECIFICATIONS` — Привязка к спецификациям (Привязка к ИБ 49)
* `FABRICS` — Привязка к тканям (Привязка к ИБ 48, до 5 коллекций)

### ИБ 47: Заявки / Лиды (`lead`)
* `STATUS` — Статус (Список, XML_ID: NEW, AGREE, PREPAY, PRODUCTION, DELIVERY, DONE)
* `PRODUCT` — Привязка к товару каталога
* `PHONE`, `SIZE`, `FABRIC`, `OPTIONS`, `ADDRESS` — данные заказа
* Поля калькулятора (создаются автоматически при первом запросе): `SPEC_ID`, `FABRIC_ID`, `HAS_MECHANISM` (Y/N), `COST_PRICE`, `PRICE_TOTAL`

## 4. Бизнес-логика расчета
1. **Материалы:** Количество (`MATERIALS_QTY`) для каждого материала округляется вверх до целого (`ceil()`) и умножается на закупочную цену (`PRICE` из ИБ 50).
2. **Ткань:** По ID цвета (ИБ 51) через `CSTAR_LINK` находим коллекцию (ИБ 48), берем `PRICE_PER_METER` и умножаем на `FABRIC_CONSUMPTION` (ИБ 49).
3. **Механизм:** Фиксированная надбавка (если выбрана).
4. **Итог:**
   $$\text{Себестоимость} = \text{Материалы} + \text{Ткань} + \text{Механизм}$$
   $$\text{Розничная цена} = \text{ceil}(\text{Себестоимость} \times \text{PRICE\_MULTIPLIER})$$

## 5. Карточка товара на витрине (catalog/template.php)
Карточка строится на основе привязанных к товару спецификаций (`arItem["DISPLAY_PROPERTIES"]["SPECIFICATIONS"]["LINK_ELEMENT_VALUE"]`):

1. **Блок "Размер"** — спецификации типа "Базовый размер" (SPEC_TYPE != OPTION). Для каждой берется `SIZE` (VALUE_ENUM), выводятся кнопки `.js-size-btn` с `data-spec-id`. Первая — активная.
2. **Блок "Комплектация и опции"** — спецификации с `SPEC_TYPE` XML_ID = `OPTION`. Выводятся чекбоксы `.js-option-btn` с `data-option-name`.
3. **Блок "Ткань обивки"** — из свойства товара `FABRICS` (привязка к ИБ 48, до 5 коллекций). Для каждой коллекции ищется цвет в ИБ 51 (сначала с `IS_MAIN_PREVIEW=Y`, иначе первый). Кнопки-свотчи с `data-fabric-id` = ID цвета (ИБ 51). Плюс кнопка "+50 тканей".
4. **Кнопка WhatsApp** — при клике собирает выбранный размер + ткань + опции в текст, создает лид через `save_lead.php`, затем открывает wa.me с номером заявки.

Важно: `data-fabric-id` у свотчей — это ID цвета из ИБ 51, а не коллекции из ИБ 48. Калькулятор умеет резолвить оба варианта (сначала пробует ИБ 48, потом ИБ 51 через CSTAR_LINK).
